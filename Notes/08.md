- stacking if statements stacks conditions to be true
- else if goes if the previous if statement wasnt true and the new if statement is true

```cpp
#include <iostream>

void ifelse(bool a, bool b, bool c)
{
    if (a)      // always evaluates
        std::cout << "a";
    else if (b) // only evaluates when prior if-statement condition is false
        std::cout << "b";
    else if (c) // only evaluates when prior if-statement condition is false
        std::cout << "c";
    std::cout << '\n';
}

void ifif(bool a, bool b, bool c)
{
    if (a) // always evaluates
        std::cout << "a";
    if (b) // always evaluates
        std::cout << "b";
    if (c) // always evaluates
        std::cout << "c";
    std::cout << '\n';
}

int main()
{
    ifelse(false, true, true);
    ifif(false, true, true);

    return 0;
}
```

```cpp
for (init-statement; condition; end-expression)
   statement;
```
- here, the initiation statement is the statement first initiated when the for loop is first ran, this is usually like a variable initiation or something
- condition = condition the loop needs to run, ends if the condition isnt valid anymore
- end-expression is something that happens every time the loop repeats, like every iteration i guess
