- constants are a value that cant be changed during the execution
- to declare a constant
```cpp
int main()
{
    int x { 4 }; // x is a non-constant variable
    const int x {12}; // x here is a constant
    x = 5; // change value of x to 5 using assignment operator, this wont work if x is a constant 
    const double gravity {9.8};

    return 0;
}
```

- constants must be initialized when you define them and that value cant be changed 
- constants can be initialized with the value of other variables including non constant ones 

- dont use constants for function value parameters because its just clutter and wont do anything

- a functions return value can be made constant but dont do that cuiz its simply ignored (some compilers may give you a warning)

> If a variable can be made constant, it generally should be made constant. This is important for a number of reasons:
- basically better optimization and lesser bugs making sure the value wont be changed accidentally

> Nomenclature: type qualifiers

>A type qualifier (sometimes called a qualifier for short) is a keyword that is applied to a type that modifies how that type behaves. The const used to declare a constant variable is called a const type qualifier (or const qualifier for short).

>As of C++23, C++ only has two type qualifiers: const and volatile.

- literals are values directly inserted into the code
```cpp
return 5;                     // 5 is an integer literal
bool myNameIsAlex { true };   // true is a boolean literal
double d { 3.4 };             // 3.4 is a double literal
std::cout << "Hello, world!"; // "Hello, world!" is a C-style string literal
```
- those all are literals 

```cpp
int main()
{
    int a { 5 };          // ok: types match
    unsigned int b { 6 }; // ok: compiler will convert int value 6 to unsigned int value 6
    long c { 7 };         // ok: compiler will convert int value 7 to long value 7

    return 0;
}
```
- you dont have to use literal suffixes so im not gonna mention

- by default floating point literals have a type of double, to make them floats you use f or F, now this seems useful
```cpp
#include <iostream>

int main()
{
    std::cout << 5.0 << '\n';  // 5.0 (no suffix) is type double (by default)
    std::cout << 5.0f << '\n'; // 5.0f is type float

    return 0;
}

float f { 4.1f }; // use 'f' suffix so the literal is a float and matches variable type of float
double d { 4.1 }; // change variable to type double so it matches the literal type double

double avogadro { 6.02e23 }; // 6.02 x 10^23 is a double literal in scientific notation
double protonCharge { 1.6e-19 }; // charge on a proton is 1.6 x 10^-19

double pi { 3.14159 }; // 3.14159 is a double literal in standard notation
double d { -1.23 };    // the literal can be negative
double why { 0. };     // syntactically acceptable, but avoid this because it's hard to see the decimal point (prefer 0.0)
```

## 5.7

- #include <string>
- std::string stores a string
- use std:;getline to std::cin a string cuz normally strings have gaps and it wont work
```cpp
#include <iostream>
#include <string> // For std::string and std::getline

int main()
{
    std::cout << "Enter your full name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // read a full line of text into name

    std::cout << "Enter your favorite color: ";
    std::string color{};
    std::getline(std::cin >> std::ws, color); // read a full line of text into color

    std::cout << "Your name is " << name << " and your favorite color is " << color << '\n';

    return 0;
}
```
- std::ws is an input manipulator that tells std::cin to ignore any whitespace thats leading
```cpp
If using std::getline() to read strings, use std::cin >> std::ws input manipulator to ignore leading whitespace. This needs to be done for each std::getline() call, as std::ws is not preserved across calls.
```

- practice:
```cpp
#include <iostream>
#include <string>

int main(){

    std::cout << "Enter something: ";
    std::string something{};
    std::getline(std::cin >> std::ws, something);

    std::cout << "You entered: " << something << "\n";
    std::cout << "Your number of characters: " << something.length();
}

```
- you can get the length of a std::string with the name of the variable and `.length()`
- however if you want to save the length as an int youll have to use 
```cpp
int length { static_cast<int>(name.length()) };
```
- cuz the compiler might complain about conversions if you dont use static_cast
