## 6.2

- arithmatic operators:
- unary operators return the operand multiplied by + or - written as +x or -x in code

- binary operators 
Addition	    +	x + y	x plus y
Subtraction 	-	x - y	x minus y
Multiplication	*	x * y	x multiplied by y
Division	    /	x / y	x divided by y
Remainder   	%	x % y	The remainder of x divided by y
- works just as in real life 

```cpp
#include <iostream>

int main()
{
    constexpr int x{ 7 };
    constexpr int y{ 4 };

    std::cout << "int / int = " << x / y << '\n';
    std::cout << "double / int = " << static_cast<double>(x) / y << '\n';
    std::cout << "int / double = " << x / static_cast<double>(y) << '\n';
    std::cout << "double / double = " << static_cast<double>(x) / static_cast<double>(y) << '\n';

    return 0;
}
```
- using static cast to convert to a double to retain the fractional values
- also i figure this stuff is useful

Addition assignment     	+=	x += y	Add y to x
Subtraction assignment	    -=	x -= y	Subtract y from x
Multiplication assignment	*=	x *= y	Multiply x by y

Remainder assignment    	%=	x %= y	Put the remainder of x / y in x
