- what is a function? a function is a reusable sequence of statements designed to do a particular job
- pretty much like the main function except main executes whenever the script is ran and the function executes whenever called in main or something like that
> The C++ standard library comes with plenty of already-written functions for you to use -- however, it’s just as common to write your own. Functions that you write yourself are called user-defined functions.
- the syntax is like 
```cpp
returnType functionName() // This is the function header (tells the compiler about the existence of the function)
{
    // This is the function body (tells the compiler what the function does)
}
```
- the returnType is usually int or void or something we'll get to return types next sub chapter apparently
- just like the main function, stuff in the curly braces are what is being ran in sequence, to call a function you just add `functionName()` in your code apparently
```cpp
#include <iostream> // for std::cout

// Definition of user-defined function doPrint()
// doPrint() is the called function in this example
void doPrint()
{
    std::cout << "In doPrint()\n";
}

// Definition of user-defined function main()
int main()
{
    std::cout << "Starting main()\n";
    doPrint();                        // Interrupt main() by making a function call to doPrint().  main() is the caller.
    std::cout << "Ending main()\n";   // This statement is executed after doPrint() ends

    return 0;
}
```

## 2.3
- covering void functions, we talked about int functions earlier
- void functions dont need a return statement and they cant be used to initialize an int variable like int x{ getInteger() }; like we did earlier
- they can however be ran, example from course:
```cpp
#include <iostream>

// void means the function does not return a value to the caller
void printHi()
{
    std::cout << "Hi" << '\n';

    // This function does not return a value so no return statement is needed
}

int main()
{
    printHi(); // okay: function printHi() is called, no value is returned

    return 0;
}
```
- pretty straight forward, prints hi 
> Do not put a return statement at the end of a non-value returning function. (even though you can put a return; it doesnt matter and trying to return a value is a compile error)
>> Void functions can’t be used in expression that require a value
